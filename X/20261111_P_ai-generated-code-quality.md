# How Do You Ensure the Quality of AI-Generated Code?

Do you review AI-generated code?

Do you ask AI to produce a test report—and then audit it?

Do you independently run the test code yourself to verify the result?

My question started with Vibe Coding applications that passed every test but were still not truly usable.

Their tests often covered the UI and a few end-to-end happy paths—not exceptions, data boundaries, hidden engineering constraints, or the real execution environment.

Then I wondered: if we add non-functional requirements and test specifications to SDD, can we ensure the quality of AI-generated code?

While studying edge cases, I reached a harder question:

If AI interprets the requirement, writes the code, generates the tests, runs them, and reports that they passed, are we seeing independent quality evidence—or one consistent inference built from the same incomplete context?
