# 是否會有人想用 AI，產生一套全新的程式語言？

Hook 是否會有人，想用 AI 產生一個全新的程式語言
先了解程式語言的概念

起點是 程式語言 是在機器語言、組合語言之後的更貼進人類語彙的一種執行邏輯語言

可以說是介於機器語言和人類自然語言的一個中間層

主要是 程式語言用人能理解的詞彙與結構，精確描述電腦要做的事；它的設計同時考慮人類閱讀、避免歧義，以及轉換成可執行指令。但語法結構不完全是為了執行效率：縮排、函式名稱等設計也常是為了讓人更容易閱讀和維護程式。
再假設

如果人類不再閱讀程式碼，人類閱讀，但是不再需要考量效率、安全等，底層會處理，也不用考量維護，是否有價值重新創建一個易閱讀的程式語言，有點類似
或是包容
- 結構化英文
- 事件趨動描述
- 商業情境分析
這些不同敘事的程式語言

或許就可以使用一種非自然語言，但可以充份表達羅輯需求，方便閱讀，方便維護的程式語言
