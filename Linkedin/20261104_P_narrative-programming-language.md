# A Programming Language for Expressing Intent

Would anyone want to use AI to create an entirely new programming language?

I started with a simpler question: what is a programming language for?

Compared with machine code and assembly, high-level languages bring execution logic closer to human vocabulary. They give us words and structures we can read, while remaining precise enough to translate into instructions a machine can run.

That design serves several human needs. We need to understand what the code does, avoid ambiguity, and maintain it as requirements change. Readability is part of the design, not just a byproduct of execution.

Now imagine a different division of work.

Suppose the underlying system takes care of performance, security, and implementation maintenance. People no longer need to read the implementation. Their attention goes to business logic, functional requirements, and use cases.

Would we still design a language around describing how a program runs?

I can imagine a language that accommodates several ways of expressing intent: structured English for rules, event-driven descriptions for reactions, and business scenarios for expected outcomes.

It would not be unrestricted natural language, where the system has to guess what a sentence means. Conditions, events, exceptions, and expected results would have explicit forms that people could read and check.

That leaves me with three questions:

Would such a language be worth building?
Would anyone want to build it?
Could AI help design and develop it?
