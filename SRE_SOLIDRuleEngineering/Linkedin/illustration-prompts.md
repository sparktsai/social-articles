# LinkedIn illustration prompts

All four illustrations use the built-in image generation path and a shared visual system: 2:1 landscape, dark navy engineering blueprint, cyan/teal traceability, and orange risk or uncertainty signals. No title text is embedded in the images.

## L_SRE_A_01

Visualize that AI makes code generation cheap, but does not make requirement change risk cheap. An abstract AI machine rapidly produces luminous code modules; a sturdy architectural boundary channels them; an orange requirement-change signal shows controlled and uncontrolled propagation paths.

## L_SRE_A_02

Visualize semantic erosion across successive AI maintenance passes. A requirement beacon begins clearly connected to an architectural model, then fades while small deviations accumulate across four generations until the polished final structure no longer aligns with its original source.

## L_SRE_A_03

Visualize SOLID as change management rather than small classes. Multiple change-driver signals enter a modular system; good responsibility boundaries contain each signal while a ghosted alternative shows tangled propagation.

## L_SRE_A_04

Visualize SOLID for AI as requirement-to-design alignment. Requirement sources flow through verified change drivers and responsibility boundaries into code modules; a human and an AI inspect traceability while an amber dotted branch preserves explicit uncertainty.
